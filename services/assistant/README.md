# Помощник «Карман»

Помощник использует RAG: выбирает подходящие фрагменты FAQ, проверенных материалов, клубов, мест на карте, общежитий, новостей УУНиТ и справочника сервисов, затем передаёт их модели. Запросы о последних новостях и ближайших событиях сортируются по датам и отвечаются прямо по ленте без ожидания модели. Для расписания он напрямую обращается к общему сервису и его базе; можно спросить о сегодняшнем, завтрашнем дне и неделе по названию или ID группы. Если группа уже выбрана на сайте, её можно не повторять в вопросе. Ответ сопровождается исходными ссылками и кнопками перехода в разделы сайта. Форумные публикации и сведения аккаунтов не индексируются. Поиск и интерфейс продолжают работать без модели, показывая найденные фрагменты с пометкой.

Четыре подсказки под приветствием и короткие обращения к помощнику («Привет», «Как дела?», «Кто ты?», «Ты кто?», «Расскажи о себе» и похожие формулировки) отвечаются сразу одинаковым текстом в браузере и в API, не вызывая модель. Классификация допускает другой порядок слов и вежливые вводные, но не перехватывает содержательные вопросы после приветствия. Перетаскивание и изменение размера окна работают во всех вкладках «Личного кампуса». Нижняя кнопка помощника сворачивает окно без потери переписки, а крестик закрывает его с очисткой переписки; при следующем открытии начинается новая сессия.

## Запуск с локальной моделью

На компьютере с Ollama один раз загрузите модель:

```sh
ollama pull qwen3:4b-instruct
```

Убедитесь, что Ollama запущена и доступна по `http://127.0.0.1:11434`. В корне проекта запустите `npm run dev` или `npm start` после `npm run build`. По умолчанию помощник использует прежнюю `qwen3:4b-instruct`; в существующем `.env` установите `ASSISTANT_MODEL=qwen3:4b-instruct`, если ранее переходили на 8b. Для CPU можно настроить `ASSISTANT_TIMEOUT_MS` (по умолчанию 90000 мс). При недоступности модели показываются найденные материалы, но текст не выдаётся за сгенерированный ответ.

На сервере с 2 ядрами и 4 ГБ ОЗУ сайт, расписание и поиск можно запускать без локальной модели (`ASSISTANT_PROVIDER=off`). Если нужен генеративный текст, используйте внешний API с серверным ключом. Локальная `qwen3:4b-instruct` занимает около 2,5 ГБ только файлом модели: вместе с системой, контекстом модели и сервисами проект может не поместиться в 4 ГБ или отвечать слишком медленно. Диск 40 ГБ для кода и этой модели достаточен, если его не заполняют другие сервисы.

Альтернатива — серверный OpenAI API: задайте в `.env` `ASSISTANT_PROVIDER=openai`, `ASSISTANT_MODEL=gpt-4.1-mini`, `ASSISTANT_API_KEY=...`. Ключ нельзя указывать с префиксом `VITE_` или в браузере. Этот режим отправляет вопрос и до трёх найденных фрагментов внешнему API; не посылайте помощнику пароли и личные данные. Без модели установите `ASSISTANT_PROVIDER=off`.

## Границы

- Источники FAQ берутся из `src/features/student-life/faq-data.ts`, сервисов — из `src/features/services/knowledge.ts`, ресурсы, события и начальные новости — из `src/features/student-life/student-life.json`. Обновлённые новости считываются для каждого вопроса из `NEWS_DATA_DIR/student-life.json` (по умолчанию `.runtime/news/student-life.json`). В `npm start` лента обновляется штатным сборщиком; в `npm run dev` без обновлённой ленты используются новости из архива. В ответах о новостях указана дата обновления ленты, поэтому ответы не выдаются за данные реального времени.
- Разделы сайта задаются в `services/assistant/knowledge.mjs`; поиск использует нормализацию русских слов из `src/features/campus/retrieval.ts`.
- По расписанию помощник использует общий сервис расписания, ту же базу групп и сохранённую в браузере выбранную группу; календарь рассчитывается в часовом поясе Уфы. Точные маршруты и сведения из личных аккаунтов он не генерирует. Форум можно подключить после отдельной модерации и настройки прав доступа.
- API `POST /api/assistant/ask` работает в dev, preview и production. Лимиты: 300 символов в вопросе, 12 запросов в минуту с IP, до трёх одновременных запросов к модели.
