# PocketUUST · RU / EN

В архиве исходники, готовая сборка `dist/`, исходный `.env`, пример `.env.example`, тестовые аккаунты и согласованные копии баз `.runtime/`. Зависимости ставятся стандартной командой.

```bash
npm ci
npm run dev
```

Для готовой сборки на сервере: `npm run build`, затем `npm start` (с существующими настройками хостинга). Требуется Node.js 24. Переключатель RU/EN находится в шапке. RU выбран при первом открытии; после переключения язык сохраняется в браузере. Помощник и его база знаний работают по-русски. Данные официальных источников, названия групп, преподавателей и сообщения пользователей показываются в исходном виде.

Вход на локальном `npm run dev` использует адрес `http://127.0.0.1:5173`. На опубликованном сайте используется `CAMPUS_PUBLIC_ORIGIN` из `.env` и HTTPS через Funnel; для данного адреса это `https://game-system-product-name.taila7361a.ts.net`. Проверка адреса запроса остаётся включённой в обоих режимах. Сообщение Funnel `Success` означает, что туннель включился; его прокси на порт 3000 сам по себе не вызывает ошибку входа. Изменения production сервера после `npm run build` применяются командой `sudo systemctl restart pocketuust`.

Если обновляете уже работающий сервер, сохраните **его** `.runtime/` и `.env`, прежде чем заменять файлы проекта: архив содержит копии из переданного проекта, а на сервере могут быть новые аккаунты и записи форума. После замены исходников и установки зависимостей выполните `npm run build` и перезапустите службу.

Локализация UI: `src/shared/i18n/english.ts` — английские строки; `src/shared/i18n/index.ts` — выбор языка; `src/shared/LanguageSwitcher.tsx` — кнопка. Новые надписи интерфейса добавляйте в словарь и показывайте через `t()` или `localize()`; строки, которые используются как ID или приходят от пользователей, не переводите.
