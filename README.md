# PocketUUST — УУНиТ в кармане

Студенческий сервис для повседневной жизни в университете: добраться до аудитории, посмотреть пары, найти сообщество и задать вопрос своим. React, TypeScript, Node.js 24 и SQLite. Без платных API и отдельного сервера базы данных.

Обновление форума и порядок установки: [docs/FORUM.md](docs/FORUM.md).

Публичный тест на Ubuntu без домена: [docs/PUBLIC-LAUNCH-UBUNTU.md](docs/PUBLIC-LAUNCH-UBUNTU.md). В этом режиме новую регистрацию можно выключить через `CAMPUS_REGISTRATION_ENABLED=false`; ранее подтверждённые тестовые аккаунты входят без SMTP.

## Возможности

| Раздел             | Что работает                                                                                         |
| ------------------ | ---------------------------------------------------------------------------------------------------- |
| Аудитории          | Маршруты между корпусами и предполагаемыми этажами, пошаговая карта, варианты из 15 общежитий        |
| Расписание         | Поиск группы, реальные данные источника УУНиТ, день/неделя, текущая пара, кэш SQLite                 |
| Студенческая жизнь | Новости с фотографиями, клубы, стажировки, курсы, гайды, скидки, интересы и сохранённое              |
| Сообщество         | Объявления «куплю / продам / отдам», мемы с очередью модерации, отзывы о прошедших событиях          |
| Сервисы            | Предварительный тариф стипендии, контакты подразделений, поиск преподавателей и история университета |
| Форум              | Категории, поиск, лайки, ответы с цитатами, личное избранное и удаление своих публикаций             |
| Баллы              | Баланс и этажи, общий рейтинг, билеты и демонстрационный обмен на мерч                               |
| Помощник           | Поиск по проверенным материалам, ответ модели со ссылками на источники и переходом в раздел сайта    |

Четыре темы: светлая, тёмная, фиолетовая УУНиТ и пиксельная. Баллы доступны в основной навигации после форума; отдельные кнопки «Игры» и «Помощник» находятся справа снизу. Иконка игры — Lucide gamepad-2, условия использования: [docs/third-party/LUCIDE-LICENSE.txt](docs/third-party/LUCIDE-LICENSE.txt).

## Запуск

Нужны Node.js **24.x** и Python **3.12+**. Python используется парсером расписания; pip-пакеты не нужны.

```sh
npm ci
npm run build
npm start
```

Открыть [http://127.0.0.1:3000](http://127.0.0.1:3000). Терминал должен оставаться запущенным. Остановка — Ctrl+C.

Для разработки: `npm run dev`, адрес [http://127.0.0.1:5173](http://127.0.0.1:5173). Для проверки сборки: `npm run preview`, порт 4173. API аккаунтов, форума и расписания доступны во всех трёх режимах. Почасовой импорт новостей работает в `npm start`; dev и preview используют встроенную подборку.

В Windows при ошибке запуска npm.ps1 используйте `npm.cmd`. Менять ExecutionPolicy не требуется. Если Python не находится, скопируйте `.env.example` в `.env` и задайте `SCHEDULE_PYTHON` полным путём к python.exe.

Первое получение расписания и внешние источники требуют подключения к интернету. При сбое расписание и новости используют ранее полученные данные с датой обновления. Статический хостинг только папки dist не поддерживает аккаунты и общий форум.

Помощник «Карман» по умолчанию использует локальную Ollama: загрузите `ollama pull qwen3:4b-instruct` и запустите Ollama до запуска сайта. Если модели нет, поиск и ссылки на материалы продолжают работать без генерации. Дополнительные настройки, вариант с внешним API и ограничения описаны в [services/assistant/README.md](services/assistant/README.md).

## Аккаунты и баллы

Регистрация: адрес **@stud.uust.ru** по умолчанию (для теста можно задать `CAMPUS_EMAIL_DOMAINS=*` и использовать любую почту), имя для рейтинга и отдельный пароль PocketUUST от 15 символов. Код на почту подтверждает владение адресом; до подтверждения вход, форум и награды недоступны. Для отправки требуется SMTP и серверный секрет из `.env.example`; без них регистрация вернёт понятную ошибку, остальные разделы доступны. Уже созданные аккаунты подтверждают адрес после входа со своим прежним паролем, сохраняя баллы и сообщения. Пароли хранятся как scrypt-хеши, cookie-сессии — HttpOnly. Код не заменяет авторизацию через ИСУ и сам по себе не доказывает действующий статус студента. Подробности: [services/campus/README.md](services/campus/README.md).

| Действие                           | Награда                                     |
| ---------------------------------- | ------------------------------------------- |
| Первое открытие публикации новости | +3 КБ                                       |
| Первое сохранение новости          | +1 КБ                                       |
| Новый путь по графу кампуса        | +2 КБ, один раз за этот путь в день         |
| Завершение мини-игры «Пять этажей» | +25 КБ, один раз в день                     |
| Новая тема форума                  | +5 форумных баллов, первые 3 темы в день    |
| Ответ на форуме                    | +2 форумных балла, первые 10 ответов в день |

Этажи прогресса: **0 / 30 / 80 / 150 / 250** заработанных КБ. Траты не снижают этаж. Маршруты с одинаковым путём графа не дают повторную награду при изменении номера кабинета. Открытие новости — доступный интерфейсу сигнал чтения; фактическое прочтение внешней статьи не измеряется. Сервер проверяет существование новости, путь, повторы и дневные лимиты.

Форумные баллы учитываются отдельно. После завершения месяца при следующем обращении пользователя каждые 50 баллов конвертируются в билет; остаток не переносится. Рейтинг включает реальные аккаунты этого сервера, без вымышленных участников.

Обмен 500 КБ на худи списывает баланс и сохраняет демонстрационную заявку. **Реальная выдача мерча и розыгрыш не подключены.** Игра проверяет серверный вызов, время и лимит награды, но не доказывает физические нажатия.

## Данные и ограничения

- Карта основана на схеме кампуса Карла Маркса, 12. Планов этажей нет; точные двери и лестницы не выдумываются.
- Новости импортируются автоматически. Дата получения и ручная проверка редакцией различаются.
- Стипендия — справка по одному выбранному тарифу из официальных приказов, а не обещание итоговой выплаты. Повышенные тарифы головного вуза не применяются к филиалам. Коэффициент и временные надбавки указаны отдельно.
- В каталоге 1783 преподавателя из официальной таблицы. Таблица не содержит факультетской привязки, личной почты и кабинетов. Проверенные контакты дирекций и лабораторный каталог доступны отдельно.
- Объявления, отзывы, очередь мемов, предложенные материалы и сохранённое хранятся в браузере. Их локальный статус указан в интерфейсе. Обсуждения форума, лайки, избранное форума, аккаунты и баллы хранятся на сервере.
- Помощник ищет по проверенным материалам и отправляет выбранные фрагменты локальной или настроенной внешней модели; не читает личные данные и сообщения форума. При недоступности модели показывает найденные фрагменты без генерации. Ответ модели нужно проверять по источнику.

Исходники проверенных сведений и дата проверки находятся в карточках. PocketUUST — студенческий проект, не официальный сервис УУНиТ.
