# Студенческая жизнь

Данные и интерфейс этого раздела независимы от расписания и поиска аудиторий.

В подборке: 35 клубов из официального каталога, 7 анонсов, 14 карьерных возможностей и 37 полезных материалов (20 авторских пошаговых гайдов, 9 карточек льгот и 8 программ/сервисов). Источники и условия находятся в карточках. Проверка подборки: 26.09.2026. Это не полный список льгот Уфы; условия организаций могут измениться. Не все льготы требуют студенческий билет: например, Пушкинская карта зависит от возраста, а СКС — отдельная карта.

Основные источники: https://uust.ru/stud-life/, https://uust.ru/student-unions/, https://uust.ru/smu/health_smu/. Последний адрес — полезные ссылки Совета молодых учёных, а не страница медицинской помощи.

Изображения сохранены локально в `assets/`; `imageSourceUrl` сохраняет их происхождение. Фотографии коллективов не выдаются за логотипы. Если официальный каталог не публикует ссылку на VK/TG, название ведёт на официальную страницу коллектива. Личные страницы руководителей не используются как ссылки на сообщество.

## Обновление новостей

```sh
npm run fetch-news
npm run test:news
npm run build
```

Импорт объединяет 8 официальных публикаций с 10 последними записями Google News RSS по запросу «УУНиТ»; повторные заголовки убираются. Google RSS обычно не содержит фотографий: настоящие фотографии загружаются с официальных публикаций. Для остальных карточек выводится заглушка. Если нужен только официальный источник: `npm run fetch-news:official`.

Эти ручные команды обновляют начальную подборку для статической публикации; после такого импорта сайт нужно пересобрать. Для автоматического режима есть `npm start`: сервер обновляет отдельный каталог новостей при запуске и раз в час, а браузер получает готовую ленту через `/api/news` без пересборки. При недоступности API остаётся последняя полученная или встроенная версия. Требования будущего хостинга и пошаговый запуск: [HOSTING.md](../../../HOSTING.md). `checkedAt: null` у автоматически полученных записей означает отсутствие ручной проверки. Дата публикации новости не используется как дата мероприятия.

При сетевой ошибке, пустой/некорректной ленте или параллельном изменении JSON прежние данные остаются. Запись защищена файлом блокировки и атомарной заменой; предыдущая версия сохраняется в игнорируемом `student-life.last-success.json`. После аварийного завершения убедитесь, что импорт не работает, прежде чем удалять оставшийся `.fetch-news.lock`.

Интересы и сохранённое хранятся в localStorage этого браузера. «Предложить материал» — локальная демонстрация с предпросмотром и удалением предложения, без серверной отправки и модерации. До 25 предложений. Очистка данных браузера удалит их.

Внизу каждой категории расположен FAQ: 18 вопросов, поиск по тексту/ключевым словам и четыре темы. Ответы с университетскими сведениями ссылаются на проверенные официальные страницы; ответы об интерфейсе описывают фактическое поведение приложения. Кнопки в ответах открывают нужную категорию и очищают прежние фильтры, чтобы результат был виден. Быстрый переход к FAQ есть в верхнем блоке. Активные фильтры можно удалить по одному; кнопки сохранения подписаны текстом.
