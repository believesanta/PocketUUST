# Проверка проекта

## Обновление форума — 29 сентября 2026

Среда: Linux, Node.js 24.19.0, Python 3.12, Chromium через Playwright.

- `npm test`: **132 проверки, 132 пройдены, 0 ошибок**.
- `npm run build`: TypeScript и сборка Vite прошли.
- Автоматические проверки включают расписание, новости, навигацию, темы, помощника, аккаунты, сессии, баллы, форум, пагинацию, локальные формы и калькулятор стипендии.
- Тестовая политика почты изолирована от пользовательского `.env`: настройка `CAMPUS_EMAIL_DOMAINS=*` больше не ломает проверку ограничения студенческого домена.

### Серверные сценарии форума

- Лайки тем и ответов: проверка входа, один лайк на аккаунт, повторные и одновременные запросы.
- Избранное: приватность между аккаунтами, сохранение в SQLite, добавление и удаление.
- Удаление: только автор, закрытие всех операций над удалённым содержимым, исчезновение из лент и избранного.
- Цитаты: ответ только внутри своей темы; удалённый исходный текст больше не выдаётся.
- Поиск по всей базе, регистр русских букв, фильтры, популярные и темы без ответов, курсоры.
- Сохранение дневных ограничений начисления после удаления и отсутствие повторного использования ID.
- Миграция старой базы сохраняет пользователей и форум; повторное открытие не повторяет миграцию.

### Браузерные сценарии

Проверено на временной базе с отдельными тестовыми пользователями и публикациями:

- Гость открывает форму входа из действия форума.
- Авторизованный участник создаёт тему, отвечает и цитирует другого участника.
- Лайки и закладки сохраняются после перезагрузки.
- Второй аккаунт не видит чужое избранное и кнопку удаления чужого поста.
- Удаление ответа и темы: отмена и подтверждение.
- Русскоязычный поиск отбирает нужную тему.
- Светлая/тёмная темы; просмотр ленты и разговора на ширине 1440 и 390 px.
- Нет горизонтального переполнения страницы на телефоне; верхняя навигация прокручивается без наложения подписей.
- Во время проверенных сценариев не было ошибок JavaScript.

Скриншоты форума просмотрены. Это не полная визуальная перепроверка остальных разделов. Тестовые обсуждения не переносятся в рабочую базу.

## Воспроизводимость

```sh
npm ci
npm test
npm run build
npm run dev
```

Для тестов расписания нужен Python из `SCHEDULE_PYTHON` или `PATH`. Основные тесты используют изолированные источники и не требуют реального расписания или отправки писем. Для первой загрузки настоящего расписания нужен интернет.

Описание новой функциональности, API и обновления базы: [FORUM.md](FORUM.md).
