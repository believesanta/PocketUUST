# Размещение PocketUUST

Для запуска на личном ПК без домена и с выданными тестовыми аккаунтами: [пошаговая инструкция Ubuntu](docs/PUBLIC-LAUNCH-UBUNTU.md).

Нужен Node.js 24, Python 3.12+, постоянный процесс и файловый диск. Сервис использует встроенный SQLite, поэтому отдельная база не требуется.

## Запуск

```sh
npm ci
npm run build
npm start
```

Сервер обслуживает порт PORT (по умолчанию 3000); HOST по умолчанию 0.0.0.0. Для локального компьютера откройте http://127.0.0.1:3000. Передавайте исходники вместе с dist: сервису нужны модули расписания, начальные новости и фотографии.

## Постоянные данные

| Настройка         | Данные                                                        |
| ----------------- | ------------------------------------------------------------- |
| NEWS_DATA_DIR     | Лента и изображения; по умолчанию .runtime/news               |
| SCHEDULE_DATABASE | База кэша; по умолчанию .runtime/schedule/schedule.sqlite3    |
| CAMPUS_DATA_DIR   | Аккаунты, сессии, баллы и форум; по умолчанию .runtime/campus |

Хостинг должен сохранять эти каталоги между перезапусками и публикациями. Runtime аккаунтов не передаётся в исходном архиве. Для резервной копии SQLite используйте совместимый механизм или остановите процесс перед копированием базы и WAL-файлов.

## Публичный сайт

Требуются HTTPS и постоянный Node-процесс. Укажите NODE_ENV=production и CAMPUS_PUBLIC_ORIGIN с точным HTTPS-origin сайта, например https://campus.example.org. Cookies получают Secure и HttpOnly; записи с другого Origin отвергаются. За обратным прокси настройте ограничения запросов и защищённый доступ к служебным данным.

Почта @stud.uust.ru используется как идентификатор; код подтверждения при новой регистрации требует SMTP. При `CAMPUS_REGISTRATION_ENABLED=false` регистрация закрыта, готовые подтверждённые аккаунты входят без письма. Восстановление пароля и вход через ИСУ не подключены; адрес сам по себе не удостоверяет студента. Не используйте такой профиль для административных решений.

## Обновления

Новости обновляются при старте и раз в час. Ошибка источника оставляет последнюю успешную версию. Расписание запрашивается для выбранных групп и кэшируется; первую загрузку обеспечьте подключением к источнику. Код, гайды и справочники меняются через новую сборку.

npm run fetch-news обновляет исходную подборку для статического режима и требует последующего build. Он не заменяет отдельный runtime-каталог запущенного сервера.

Статический хостинг папки dist подходит для просмотра интерфейса и встроенной подборки, но не предоставляет общий форум, аккаунты, баллы и живое расписание.

Подробности: services/campus/README.md и services/schedule/README.md.
